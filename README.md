## Task 1: Registration Form
**Description:**  
Developed a robust registration form that allows users to sign up seamlessly. This task emphasized the importance of user experience and data security.

**Technologies Used:**
- HTML
- CSS
- Node.js
- MongoDB

**Key Features:**
- User-friendly interface for easy sign-up.
- Secure storage of user information in MongoDB.

## Task 2: Budget-Friendly Fitness Blog
**Description:**  
Created a dynamic "Budget-Friendly Fitness Blog" where users can read and write posts. This task allowed me to explore content management and user interaction.

**Technologies Used:**
- HTML
- CSS
- Node.js
- MongoDB

**Key Features:**
- Dynamic blog interface for posting and reading articles.
- Efficient data storage and retrieval using MongoDB.

**Technologies Used:**
